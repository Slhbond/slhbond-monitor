# Slhbond-Monitor v1.21

三件事：**自动检查收敛到每天 0 点**、**新增浅色主题**、**多加速节点测速择优**。
另外修了几个界面问题，并给更新加了二次确认。

---

## 新增：更新加速节点（测速择优）

国内直连 github.com 时，**TCP 连接就要 19～36 秒**，2.4 MB 的发布包经常直接超时。
现在支持配置多个加速节点，**每次下载前逐个测延迟，自动用最快的那个**：

```ini
update_mirrors = https://gh-proxy.com/,https://ghfast.top/,https://ghproxy.net/,https://hk.gh-proxy.com/
update_manifest_via_mirror = true
```

实测（本机，RK3568）：

| 路径 | 耗时 | 结果 |
| --- | --- | --- |
| 直连 github.com | 19～36 s | 多数超时失败 |
| gh-proxy.com | 0.79 s | ✓ |
| ghfast.top | 1.33 s | ✓ |
| ghproxy.net | 1.53 s | ✓ |
| hk.gh-proxy.com | 4.21 s | ✓ |

**信任边界没有变化**：

- 节点只是搬运工，内容必须与官方一致，否则 SHA-256 校验失败、拒绝安装
  （已实测：走 gh-proxy.com 下的包摘要与官方**完全一致**）
- 清单优先直连；只有直连失败才退到节点，日志会写明
  「清单取自加速节点 xxx，包体仍按官方清单里的 SHA-256 校验」
- 接口也能看到：`manifest_via_mirror` / `manifest_mirror` / `manifest_mirror_ms`
- 拉清单的超时从 8 秒放宽到 25 秒，并且外层看门狗比 curl 自己的 `--max-time`
  多留 5 秒 —— 之前两者相等，慢一点就会被外层先杀掉，误报成「下载失败」

## 新增：深色 / 浅色主题切换

面板右上角（刷新、复制按钮右边）多了太阳 / 月亮图标：

- 深色下显示太阳（点了变浅色），浅色下显示月亮
- 选择记在浏览器本地，刷新后保持
- 首屏绘制前就套用，不会先闪一下黑底
- 跟随 `prefers-reduced-motion` 关闭切换动画

不是简单反色：整个样式表 40 处白色叠加和 12 处阴影改成 `--overlay` / `--shade`
基色，浅色下基色反转为深色低透明度；进度条空槽单独用 `--track` 加强；
状态文字换成浅底上有对比度的深色变体；卡片阴影在浅色下减弱。

## 修复

- **浅色主题下溯源时间轴仍是一整条黑底**：`.trace-bar`、日期选择浮层、
  面板遮罩三处原来是硬编码深色，现在走 `--float` / `--scrim` 变量，跟着主题走
- **滑块拖柄**改用 `--knob`（两套主题都用白点 + 蓝环），浅色下不再是黑点
- **更新现在必须二次确认**：点「更新可用」先弹出「当前 vX → vY、发布说明、
  会发生什么」，只有点「确认更新」才开始下载；取消、点遮罩、Esc 都只是关掉，
  **不会下载任何东西**。焦点默认放在「取消」上，避免顺手回车就更新了线上机器
- **超时赛跑**：`slh_run_command` 看门狗与 curl `--max-time` 原来相等，
  慢请求会被外层先杀掉并误报失败
- **去掉「每 5 秒自动刷新」那行提示**，界面更干净

## 变更：自动检查只在每天 0 点

```ini
update_daily_hour = 0    # 每天 00:00 查一次
update_interval = 0      # 0 = 不按间隔轮询（默认）
```

想更及时就设 `update_interval = 1800`，两种检查取更早的那个；
两个都关则只能点「检查版本」手动查，面板会显示「仅手动检查」。

## 默认清单地址

全新安装的默认清单地址指向本项目的「最新 Release」，装完不用改任何配置就能收到更新：

```ini
update_manifest = https://github.com/Slhbond/slhbond-monitor/releases/latest/download/update.json
```

## 升级方式

```bash
tar xzf slhbond-monitor-1.21.tar.gz
cd slhbond-monitor-1.21
sudo ./deploy.sh install      # 配置文件会保留
```

或者在旧版本面板上点「检查版本」→「更新可用」→（确认）→ 自动完成。

## 验证

- 真机接口与逻辑验收 **157 项全通过**
- 加速节点实测：直连被打断后自动走 gh-proxy.com（1065 ms），检查成功
- 更新确认实测：弹框后服务端 `phase` 仍是 `idle`；取消后仍是 `idle`；只有确认后才变
- 主题实测：背景 `rgb(13,15,19)` → `rgb(238,242,247)`，刷新后保持
- 时间轴实测：深色 `rgba(21,26,34,.94)` → 浅色 `rgba(255,255,255,.96)`
- `make check`（`-Werror` + 严格转换告警）零告警
